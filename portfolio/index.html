Featured Project

PeakCut

Self-hosted tool that turns long videos and live streams into captioned vertical clips (9:16) ready for social media. Bring your own AI API key.

  • AI-powered highlight detection (Gemini, OpenAI, Grok, Groq, OpenRouter, Claude, Ollama)
  • Word-by-word animated captions in 3 styles
  • Live clipping: records streams into rolling buffer, clips highlights in real-time
  • YouTube, Instagram, TikTok integration for auto-posting
  • Runs locally, no sign-in required
